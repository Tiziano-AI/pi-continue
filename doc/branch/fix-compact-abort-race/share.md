# 协作摘要

- 根因：自动续接先调用 `ctx.abort()`，随后 `ctx.compact()` 再次中止；自然结束路径可能在两者之间完成原生压缩，后者因此报 `Already compacted`。
- 修复：成功启动 handoff 时仅调用 `ctx.compact()`，由 Pi 独占活动运行的中止与压缩；失败、重复触发时的保护性中止保持不变。
- 范围：未引入 PR #14 的原生压缩接管行为；对应上游 Issue #11。
- 验证：类型检查通过；6 项定向回归通过；隔离配置后的完整套件 227 项中 224 项通过，3 项既有 Windows 可移植性测试失败（CRLF、`npm` 命令解析、路径分隔符）。
